I'm a catgirl on the internet who enjoys Linux, self-hosting, cybersecurity, automation, and building things that probably didn't need to exist.

What started as a few scripts and some server tinkering gradually became a collection of interconnected services, experimental projects, Discord bots, and locally hosted AI personalities.

Somewhere along the way, I started naming everything after mythology.

**Things have escalated since then.**

## 🪄 Welcome to the chaos

I like building things that are useful, interesting, slightly ridiculous — preferably all three.

- 🖥️ **Homelabbing** — Virtualization, containers, self-hosting, and infrastructure that grows suspiciously quickly.
- 🕸️ **Cybersecurity** — Honeypots, deception systems, telemetry, and watching what the internet does when nobody is looking.
- 🤖 **AI & bots** — Local language models, Discord integrations, and questionable personality experiments.
- ⚙️ **Automation** — Spending three days automating a five-minute task. For efficiency, obviously.
- 🌐 **Web development** — Dashboards, websites, APIs, and interfaces for things that probably didn't need interfaces.
- 🐈 **Experiments** — Because "wouldn't it be funny if..." is a perfectly valid project specification.
