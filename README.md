I'm a catgirl on the internet who enjoys **Linux, self-hosting, cybersecurity, automation, and building things that probably didn't need to exist**.

What started as a few scripts and some server tinkering has somehow become a collection of interconnected services, deception systems, Discord bots, and locally hosted AI personalities.

Somewhere along the way, I started naming everything after mythology.

**Things have escalated since then.**

## 🏛️ The digital pantheon

*Most projects have mythological names. Some have personalities. A few probably deserve supervision.*

### 🕸️ Security & deception

**Arachne · The watcher in the web**

An experimental honeypot ecosystem built around **synthetic websites, fake application surfaces, attack telemetry, and a rather elaborate fictional infrastructure**. The internet is invited to yell at the cardboard; Arachne records what happens.

**The Observatory · A window into the noise**

Dashboards and visualizations for exploring the activity Arachne collects. Because collecting telemetry is fun, but watching the chaos unfold is better.
